# Reproducibility status

The scientific evidence is local; no external artifact retrieval is required. `reproducibility/original/` preserves original relative paths, source files, all 4,383 scientific freeze entries, immutable candidate waveforms, the 2,000-device cohort, all 10,000 production records, numerical repeats, bootstrap records and reviewed implementation. Copied artifact hashes are independently checked against originals. Research reports in `results/` are navigational copies; authoritative originals live in the provenance tree.

Run `python scripts/verify_release.py` for read-only SHA256 checks. The scientific manifest uses paths relative to `reproducibility/original/results/preconfirmatory_checks_v1/`. The final release manifest records every shipped file except itself, avoiding a self-referential hash. Original file bytes are verified by the preservation report. Operational records with machine-local paths are excluded and listed with their original hashes in `reproducibility/privacy_exclusions.json`; this is not a replacement scientific manifest. Historical broader preservation manifests may reference these excluded operational files or other exploratory runs not shipped. Their original bytes remain preserved, and their scope is not falsely presented as fully portable.

The package install and all six demonstration commands were tested using the existing pinned scientific dependencies. An isolated wheel installation was tested with those dependencies supplied from the existing environment; a clean network dependency download was not tested. GitHub Actions is supplied but has not run remotely. CPU-only execution does not import JAX. GPU qualification is historical and was not rerun during release preparation. Dependency installation still needs a package index or a separately prepared wheelhouse.

Do not execute the frozen confirmatory campaign again. It would require the original accepted execution context, source hashes, and singleton registry; the portable package is not a new accepted executor. No independent devices, bootstrap outcomes or scientific results were regenerated for release preparation. Examples use a separate development-only seed. Statistical inference and validation outcomes remain unchanged.
