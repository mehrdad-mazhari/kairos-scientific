# Exclusions

The original project is retained unchanged. This release excludes virtual environments, Git metadata, compiler caches, Python caches, temporary locks, bundles duplicating selected artifacts, redundant historical smoke runs and unrelated legacy assets. All files referenced by the frozen scientific manifest are included even if intermediate; production channels are retained because they support auditability. Selected authoritative evidence is byte-identical under `reproducibility/original/`. The inventory records the remaining original files, including excluded exploratory outputs. No external archive or download link exists or is claimed. No Git LFS is required for the present per-file sizes; archive research data separately if future growth warrants it.

Machine-local operational records are excluded with original hashes in `reproducibility/privacy_exclusions.json`. The singleton validation registry is an execution-location record, not a statistical result. Its omission intentionally prevents treating this portable archive as an authorized fresh execution location. Original originals remain untouched.

The obsolete original README copy is omitted from public documentation because it contained a personal contact address and superseded scientific claims. Its hash remains in the original inventory.
